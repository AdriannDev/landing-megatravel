# Cupos: guía actual

El saldo compartido fue sustituido por cupos independientes por fecha y origen. Consulta [la guía de carga, ajustes, correo y migración](cupos-por-salida.md).

Los campos del programa son valores iniciales de nuevas salidas. El comando que consolidaba cantidades está retirado. Las migraciones históricas permanecen para reconstruir el esquema; no deben ejecutarse como una carga o conciliación actual.
